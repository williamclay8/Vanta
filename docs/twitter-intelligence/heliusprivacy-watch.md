# HeliusPrivacy Watch Item

HeliusPrivacy is the primary Solana-native privacy benchmark for Vanta release planning.

## Cadence

Run this watch before every major Vanta release and at least monthly while Solana privacy narrative is moving quickly.

## What To Track

- product releases and feature drops;
- on-chain usage or adoption metrics;
- privacy model, especially local proving versus server-side proving;
- wallet UX, discovery, viewing-key, receipt, and trust packet patterns;
- positioning versus Vanta's counterparty-verifiable private settlement direction;
- technical primitives, relayer design, indexer design, docs, repos, and audits.

## Output Format

Each pass should end with:

- one-paragraph summary of latest movement;
- key differentiator versus Vanta;
- risk or opportunity for Vanta;
- recommended action: copy, counter, ignore, deep read.

## Claim Boundary

This file is a recurring intelligence surface. It is not evidence that HeliusPrivacy has shipped a production system, and it is not a reason for Vanta to lift any privacy or mainnet-readiness claim.
